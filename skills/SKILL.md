## 🚀 子代理并发提速架构（当台词较长或用户要求“快一点”时必用）

当字幕行数较多（> 30 句）或用户明确要求“**快一点**”、“**并发**”、“**调用子代理**”时，智能体必须采用**“分块并发分析 ➔ 单次原子写回”**的高性能架构：

### 1. 为什么不能让多个子代理同时写同一个草稿？
* 剪映草稿全部存储在唯一的 `draft_content.json` 中。若多个子代理同时直接修改文件，必然产生**文件写入竞争冲突（Race Condition）**，导致草稿损坏或数据丢失；
* 因此：**“分析与校对”充分并发，“工程写入”单次原子执行**。

### 2. 三步并发流水线（极速零冲突）
* **第一步：主代理切片分发（Parallel Dispatch）**：
  - 主代理按 20~30 句为一个批次切片，调用 `task` 并发派发 N 个子代理；
  - 每个子代理独立且同时完成：专有名词纠错、标点清除、长句 `\n` 对称折行、核心重点词高光标注。
* **第二步：内存秒级汇聚（In-Memory Merge）**：
  - 主代理等待所有子代理交付，毫秒级拼接为完整的标准台词与重点词列表。
* **第三步：极速原子写回（Atomic One-Shot Writeback）**：
  - 主代理一次性将汇聚好的参数喂给 `auto_subtitle_workflow.py` 或 MCP 工具；
  - 释放锁 ➔ 单次加密 ➔ 多副本覆盖 ➔ 重载打开，全程耗时仅 2~3 秒，零冲突、零等待！

### 第二步：智能校对与纠错铁律

智能体对字幕逐句进行专业校准，严格遵循四大规则：

1. **【铁律】严格 1 对 1 行数对齐（总行数绝对守恒）**：
   - 校对后的列表长度必须与原文本行数完全相等（`len(corrected_lines) == len(lines)`）；
   - **严禁擅自合并行或跨行拆分**，确保每一行对应剪映时间轴上的一个独立字幕切片！
2. **清除口语废话与结巴卡顿**：
   - 彻底剔除“这个呃”、“然后呢”、“啊”、“那额度了”、“嗯”、“诶”等口语碎词，保持呼吸感与节奏感。
3. **专有名词与技术模型专业校准（结合本机事实）**：
   - `Claude open 十五点五` / `OPPO S5.5` ➔ **Claude Opus 5.5**
   - `GPT6.1SO` ➔ **GPT-6.1-Sol**
   - `workbody的H3` ➔ **WorkBuddy 的 Hy3**
   - `GPT plus` / `Claude的Pro` ➔ **ChatGPT Plus** / **Claude Pro**
   - 专业工具正字：`FocuSee`、`OpenFilm`、`FaceFusion`、`overlay-studio` 等。
4. **语法倒错纠偏**：
   - 修正“审美了很好” ➔ “审美非常好”、“我给他建议” ➔ “我给大家的建议”。

### 第三步：调整字幕样式与音量标准（克制、高保真、杜绝花里胡哨）

在写回剪映时，以**用户舒适阅读的「纯净基础字幕」为默认标准**，杜绝过度包装：

#### 1. 核心铁律：用户逐字稿 100% 守恒
- **严禁擅自拆分或合并用户的句子**：用户提前录制并对齐好的逐字稿，每一句都对应特定的节奏与镜头，严禁私自将单句拆碎。
- **默认单层基础字幕**：未经用户明确要求，**严禁私自叠加胸前重点大字、头顶标题轨或背景音效轨**，保持口播视频的自然纯净。

#### 2. 基础字幕黄金排版规范（Aa研宋体经典阴影 + 句内放大高亮）
| 属性 | 标准参数 | 为什么这么定 |
|---|---|---|
| **字体** | **Aa研宋体** (`7130644288047682085`) | 文化感、高级感，笔画纤细有力，耐看且不落俗套。 |
| **普通文字字号** | **`13.0`** | 竖屏手机阅读的黄金尺寸，不大不小，绝不挤压画面两边。 |
| **文字颜色** | 纯白（`#FFFFFF`） | 纯净通透。 |
| **标点符号铁律** | **彻底删除所有标点符号** | 杜绝句末逗号句号；较短停顿用单个**空格**隔开。 |
| **长句分行与对仗美学（核心铁律）** | **按语义匀称折行（插入 `\n`）** | • **【铁律一：绝对杜绝单字掉行（寡字）】**：超过 10 字的长句必须主动插入 `\n`，严禁任由剪映右边距自动换行导致最后一个字孤零零掉到第二行（如 `大家就当和我一起云创业就 / 行` ❌ ➔ 改为 `大家就当和我一起 \n 云创业就行` ✅）！<br>• **【铁律二：绝对杜绝倒金字塔失衡（寡词孤立）】**：严禁机械按逗号切分导致第一行仅 2~3 个字（如 `最后`、`请放心`）而第二行塞 11 个字；必须将停顿后的前半部分连词或主语拉入第一行，保持两行字数比例在 1:1 ~ 1:1.5 内（如 `最后 如果我的内容 \n 对你有帮助` ✅、`请放心 我会用 \n 最通俗的语言去描述` ✅），视觉匀称稳重！ |
| **重点词强调** | • **字号显著放大至 `16.5`**<br>• **文字加粗 (`bold = True`)**<br>• **高饱和亮金黄 (`[1.0, 0.88, 0.15]`)** | **【核心交付标准】** 在同一个字幕片段内实现主次分明，重点词瞬间聚焦跳出，既不遮挡博主面部，又有极强视觉冲击力！ |
| **阴影参数** | • 透明度：`60%` (`alpha = 0.6`)<br>• 模糊度：`6%` (`0.010`)<br>• 距离：`6.0`<br>• 角度：`-60.0°` | 无论博主穿白衣服、浅色衣服还是背景杂乱，文字立刻立体浮现，100% 保证清晰识别。 |
| **画面位置（竖屏 9:16 终极黄金安全区）** | **`y = -0.42`**<br>*(真机发布反复实测唯一最佳解)* | **【真机实测终极铁律：`y = -0.42`】**<br>• **抖音/视频号真机动态避让**：实测截图证明，真机发布后下方经常会弹出「已为你智能生成章节 / 推广标签 / 定位」等动态横条，导致底部的“头像+文案卡片”整体被向上顶起 50~80px！若设在 `-0.50` 就会贴在卡片上沿；<br>• **黄金解法锁定 `y = -0.42`**：将字幕精准固定在 `y = -0.42`（距底边约 560px），无论平台弹出什么横条都绝不碰字幕，同时稳稳落在主播领口衣服区，上绝不顶下巴，达到 100% 完美视觉平衡！<br>• **横屏 16:9 严禁套用**：横屏界面布局完全不同，维持默认。 |

#### 3. 场景化重点词动画与卡点音效规范（心法：懂语境、知克制）

在口播视频中，字幕动效的灵魂在于**“根据当时的语境与情绪，赋予最匹配的进场姿态”**，同时遵守**“严格克制，绝非每个重点词都加”**的铁律：

1. **克制率铁律（20%~30% 原则）**：
   - 全片绝不能句句加动画（全加等于没加，且会造成严重视觉疲劳）；
   - 仅对全片最核心的 **5~8 处关键情绪转折点** 赋予入场动效，其余重点词仅保留句内放大 16.5 + 亮黄高亮（静态呈现），形成**“动静交替、有张有弛”**的自然节奏。

2. **五大语境与推荐入场动画匹配心法**：
| 场景与语境 | 典型台词情绪 | 最佳推荐动画（免费 0.4s） | 动画视觉语言 | 匹配音效库 |
|---|---|---|---|---|
| **顺承引出 / 观点推进** | 介绍网址（如 dqtx.cc）、引出方法论、展示成果 | **向右缓入** (`1488722`)<br>*(字从左边顺滑进入)* | 符合从左到右阅读习惯，顺畅优雅，视觉引流极佳。 | `whoosh.mp3`（极速破风） / `card-flip.mp3`（翻牌） |
| **技术硬核 / 开场破冰** | 抛出全片最大底牌、公开项目、代码与实战 | **打字机 I** (`1644275`) | 敲击出的即时记录感，前 3 秒黄金留存率最高。 | `type-fast.mp3`（机械打字声） |
| **痛点反差 / 情绪沉重** | “踩了很多坑”、“完全为 0”、“长达2年没收入” | **轻微放大** (`1644262`)<br>或 **放大** (`1644264`) | 视觉突然一顿或微突，强化反常识、警醒与同理心。 | `drop-thud.mp3`（低音定格） / `error-tone.mp3` |
| **顿悟灵感 / 核心干货** | “商业灵感”、“少走弯路”、“核心秘诀” | **日出** (`1644269`)<br>或 **向上滑动** (`1644267`) | 向上升起与泛光感，视觉暗示“这是高价值干货”。 | `success-chime.mp3`（清脆金币叮） |
| **号召转粉 / 温暖收官** | “点个关注”、“期待未来”、“云创业” | **向上翻转** (`8945307`)<br>或 **向右缓入** (`1488722`) | 亲和力强，自然促成点赞与关注。 | `sparkle.mp3`（星光微光） / `brand-stamp.mp3` |

* **音效搭配铁律**：音效仅与这 5~8 处动效毫秒级同步触发；音量严格卡死在 `0.55 ~ 0.65`（约 `-14 dB`），只做人声的轻量空气感点缀，绝不允许盖过主播人声。

#### 4. 人声音频标准（标准广播级响度 +7.0 dB）
- **人声基础音量**：自动默认设为 **`+7.0 dB`**（底层线性增益 `volume = 2.2387`，不大不小刚刚好，整体波峰不超 6dB，绝不过曝且人声饱满清晰）；
- **免手动微调**：MCP 底层自动固化 `+7.0 dB` 标准参数写入工程，用户无需手动在剪映中逐个拖动音频滑杆。
